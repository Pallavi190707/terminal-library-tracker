# Problem Statement

Many readers and library enthusiasts struggle to keep track of the books and series they are currently reading, the ones they want to read next, and the titles they have already completed. Manual tracking through notes, spreadsheets, or memory often leads to missed reading goals, inconsistent progress updates, and difficulty managing a growing list of books and series. The Terminal Library Tracker addresses this problem by providing a simple command-line tool that helps users organize their reading habits in one place.

The project aims to automate basic reading log activities such as adding new series, updating reading progress, managing book wishlists, and rating finished titles. By making these tasks quick and easy through a terminal interface, the tool reduces administrative overhead and helps readers stay consistent with their reading routines.

# Scope of the Project

The scope of the Terminal Library Tracker includes the management of reading-related records through a command-line application. The project will support the following activities:

- Adding new series and books to a personal library database
- Updating reading progress for ongoing books or series
- Recording completed books and assigning ratings
- Managing a wishlist of titles users want to read later
- Viewing and organizing reading data in a structured way
- Supporting repeated use in a terminal-based workflow for quick updates

The project is focused on basic reading-log functionality rather than full-scale library management or online catalog integration. It is designed as a lightweight, user-friendly tool for personal tracking and organization.

# Target Users

The Terminal Library Tracker is intended for:

- Readers who want a simple way to track what they are currently reading
- People who maintain multiple book series and need to monitor progress over time
- Users who prefer terminal-based tools for productivity and organization
- Students, hobby readers, and book enthusiasts who want a lightweight personal library management system
- Anyone looking for a straightforward way to log reading activity without using heavy graphical applications

# High-Level Features

The application will include the following high-level features:

- Series Management: Add and maintain information about book series
- Reading Progress Tracking: Update progress for books and series as users read through them
- Wishlist Management: Save titles users want to add to their reading list later
- Completion and Rating: Mark titles as finished and record user ratings
- Quick Terminal Interface: Provide a command-line experience for efficient record keeping
- Personal Library Organization: Keep reading history and status in an organized collection for easy access

These features are intended to make reading tracking simple, efficient, and easy to maintain for everyday users.
